Build a debounced search bar

🔥 11-day streak · submit today to keep it alive

The task

Every product with a search box has the same problem: firing a request on every keystroke murders your backend and your UX. Today you're building the fix — a search input that waits until the user actually stops typing before it does anything.

What to build

  • A text input with a live results list below it, using any dummy dataset.
  • A debounce of 300ms so the search only runs after typing pauses.
  • A loading state while the "search" is in flight.
  • An empty state for zero matches — don't just show a blank list.

A nudge, not a solution

Debouncing means: reset a timer on every keystroke, and only act once the timer finishes uninterrupted. Look up setTimeout + clearTimeout, or write your own useDebounce if you're on React. Don't reach for a library today — build the mechanism once so you understand it.
